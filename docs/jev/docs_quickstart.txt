Try it: the Playground

Open the 
Playground
 and log in.

Paste any text
 as the state.

Sample state
Hi, I've been trying to connect my Stripe account for 3 days and the integration keeps failing. I'm losing sales. Please help ASAP.

Add a question.
 Try a Noul question: 
"Does this message express urgency?"

{

  "urgency"
: {

    "type"
: 
"noul"
,

    "instructions"
: 
"Does this message express urgency?"

  }

}

Add more questions.
 Mix Noul, Choice, and Score in one call and see all results at once.

 from the 
dashboard

Make a POST request
 to the API endpoint

API Reference
 for all the details.

POST
 https://api.typesafe.ai/v1/systemone

Authorization
:
 Bearer <API_KEY>

Content-Type
:
 application/json

Code it: the Python SDK

Install the SDK
 (requires Python >= 3.10).

With pip
pip
 install
 typesafe-sdk

With uv
uv
 add
 typesafe-sdk

Use the SDK.
 The client reads 
TYPESAFE_API_KEY
 from the environment and calls 
jev-latest
 by default.

from
 typesafe_sdk 
import
 Choice, Noul, Score, TypeSafeClient

client 
=
 TypeSafeClient()

ticket 
=
 "Hi, I've been trying to connect my Stripe account for 3 days and the integration keeps failing. I'm losing sales. Please help ASAP."

response 
=
 client.system_one(

    state
=
ticket,

    questions
=
{

        "department"
: Choice(

            instructions
=
"Which team should handle this"
,

            criteria
=
{

                "billing"
: 
"Payment or subscription issues"
,

                "technical"
: 
"Bugs or integration problems"
,

                "sales"
: 
"Pricing or account questions"
,

            },

        ),

        "frustration"
: Score(

            instructions
=
"How frustrated the customer appears"
,

            criteria
=
[

                "Calm, just stating facts"
,

                "Frustrated but civil"
,

                "Very angry, strong language"
,

            ],

        ),

        "is_urgent"
: Noul(

            instructions
=
"The message conveys urgency or time-sensitivity"
,

        ),

    },

)

print
(response.answers[
"department"
].choice)  
# "technical"

print
(response.answers[
"frustration"
].score)  
# 1.0

print
(response.answers[
"is_urgent"
].noul)     
# 1.0

See 
client SDKs
 for installation options and detailed usage.
